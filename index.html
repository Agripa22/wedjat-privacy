Wedjat — Privacy Policy

Last updated: 2026-09-19

Wedjat is built to do one job — show you your own public IP, ISP and location information — without collecting anything about you in the process. Its name comes from the Eye of Horus (the Wedjat) of ancient Egyptian mythology, a symbol of protection and watchfulness — fitting for an extension whose only purpose is to show you what the internet sees when it looks at your connection.

What the extension does

When you open the popup, Wedjat sends a single request to a third-party IP-lookup service (ipwho.is, with ipapi.co and api64.ipify.org as automatic fallbacks if the first is unreachable) to ask "what is the public IP of this connection?" That request necessarily includes your IP address, because that's how the internet works — the lookup provider sees it the same way any website you visit would. Wedjat does not add any identifying headers, cookies, or tracking parameters to that request.

What we collect

Nothing. Wedjat has no server of its own, no analytics SDK, no crash reporting, and no advertising code. We (the developer) never receive your IP address, your browsing history, or any other data from your use of this extension.

We do not sell, rent, or share your data with anyone — ever. There is no data pipeline to monetize: nothing about your usage, your IP history, or your device is collected in the first place, so there is nothing to sell. This will not change in a future update without this policy being updated first and made obvious in the extension's changelog.

What is stored locally

  • The most recent IP lookup result is cached in your browser's local extension storage for up to 5 minutes, purely to avoid unnecessary repeat requests. It never leaves your device.
  • Your preferences (language, theme, whether the toolbar badge is enabled) are stored the same way.

None of this data is synced to an account, sent to us, or shared with any third party beyond the lookup request described above.

WebRTC leak check

The WebRTC leak check runs entirely inside your browser using a local, non-connected RTCPeerConnection. It does not contact any server, signaling service, or STUN/TURN server — it only inspects the ICE candidates your own browser generates locally.

Optional toolbar badge

If you turn on "Show country flag on toolbar icon" in Settings, the extension will periodically (about every 15 minutes) repeat the same IP lookup in the background to keep the badge current. This is off by default. Turning it off returns the extension to zero background network activity.

Optional IP change alerts

If you turn on "Notify me when my public IP changes" in Settings, the extension periodically (about every 15 minutes) repeats the same IP lookup in the background and compares it with the last IP it saw, stored only in your browser's local extension storage. If it changed, you get a native browser notification. No history of past IPs is kept beyond the single most recent value needed for that comparison, and nothing is sent anywhere except the same lookup request described above. This is off by default.

Optional "Buy me a coffee" link

Settings includes an optional, clearly-labeled link to the developer's Buy Me a Coffee page for anyone who wants to voluntarily support the project. Clicking it opens that external, third-party site in a new tab — it is not embedded, does not run any code inside the extension, and Wedjat shares no data with it. Not clicking it changes nothing about how the extension works.

Permissions

  • storage — to save your preferences and the short-lived cache described above, locally.
  • alarms — only used if you opt in to the toolbar badge or IP change alerts.
  • notifications — only used to show the native alert when your IP changes, if you opt in to that feature.
  • Host access is limited to the three IP-lookup domains named above — Wedjat cannot read or modify any web page you visit.

Third-party providers

Requests are sent to ipwho.is, ipapi.co, and ipify.org. Each operates under its own privacy policy governing how it handles the lookup request it receives.

Changes

If this policy changes, the updated version will ship with the extension update and the "Last updated" date above will change.
